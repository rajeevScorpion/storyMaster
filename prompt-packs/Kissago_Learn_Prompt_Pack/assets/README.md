# Assets Folder

Place future production assets here before handing the pack to the AI coder.

## Folder structure

```text
assets/
├── backgrounds/
├── screenshots/
├── illustrations/
└── asset-manifest.sample.json
```

## Backgrounds

Expected future filenames:

- `bg-01-story-seed.webp`
- `bg-02-fragmented-creation.webp`
- `bg-03-calm-attention.webp`
- `bg-04-story-convergence.webp`
- `bg-05-character-continuity.webp`
- `bg-06-episodic-world.webp`
- `bg-07-create-invitation.webp`

## Screenshots

Use names from `07_SCREENSHOT_AND_ASSET_PLAN.md`.

## Illustrations

Optional supporting visual elements should be exported with transparent backgrounds where useful.

## Important

- The `/learn` route must work even when these folders are empty.
- Do not include font files.
- Do not place personal data in screenshots.
- Do not bake required explanatory text into artwork.
- Optimize production assets before shipping.
