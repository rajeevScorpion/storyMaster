# Research Sources and Notes

This is a short curated source list for the coder to verify during implementation.

## PixiJS
- Official docs: https://pixijs.com / https://pixijs.download/release/docs/index.html
- Notes: High-performance 2D rendering, filters, masking, sprites, WebGL/WebGPU support.

## PixiJS Particle Emitter
- Repo: https://github.com/pixijs-userland/particle-emitter
- Notes: MIT-licensed particle system for PixiJS, includes examples and an interactive editor reference.

## Pixi Filters
- Repo: https://github.com/pixijs/filters
- Notes: MIT-licensed collection of filters for PixiJS.

## tsParticles
- Docs: https://particles.js.org/
- Repo: https://github.com/tsparticles/tsparticles
- Notes: Useful as fallback particle overlay solution.

## Puppeteer
- Docs: https://pptr.dev/
- Repo: https://github.com/puppeteer/puppeteer
- Notes: Useful for headless browser automation, testing, and possible rendering support.

## FFmpeg
- Official: https://ffmpeg.org/
- License notes: https://www.ffmpeg.org/legal.html
- Notes: Good fit for encoding final exports. Validate licensing/build configuration.

## ffmpeg.wasm
- Repo: https://github.com/ffmpegwasm/ffmpeg.wasm
- Notes: Useful for experiments only unless clearly justified for production.

## Important licensing note
If evaluating any video rendering stack such as Remotion, validate its license carefully before adoption. Do not assume it is a plain permissive OSS dependency.
